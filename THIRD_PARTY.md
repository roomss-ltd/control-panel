# Third-party software

The control panel itself is MIT-licensed (see [LICENSE](LICENSE)). The Go code has no dependencies
beyond the standard library. The web UI in `web/` bundles the third-party files below.

Licences are taken from the file headers, from `scripts/vendor/package.json`, or from the source
comments that credit the original. Where a file carries no licence text, the entry says so and
names the upstream licence as *unverified*: check it against the upstream project before you
redistribute a build.

## Tools the panel runs but does not ship

The panel starts programs that you install separately (zellij, cloudflared, Chromium, gh, ripgrep,
ImageMagick, ffmpeg, TigerVNC, faster-whisper, the `claude` and `codex` CLIs). They keep their own
licences; nothing of them is copied into this repository.
